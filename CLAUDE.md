# robrun_linux

An EOS SDK replacement for ROB RUN under Steam Play/Proton. The game loads
`EOSSDK-Win64-Shipping.dll` from its plugin folder; this tree builds that file
and answers the game's Epic Online Services calls locally.

## What this tree is

- `shim/` — the proxy DLL. One translation unit per concern: `core/boot.cpp`
  (log, stub), `core/diag.cpp` (shared diagnostic slot), `abi/eos.cpp` (EOS
  surface), `abi/anticheat.cpp` + `abi/anticheat_policy.cpp` (anti-cheat client
  surface and the mode policy).
- `shared/include/` — headers the shim includes.

Build with `./build.sh` (MinGW cross) or `shim/build.bat` (MSVC). The export
surface must stay at 681 names; `shim/bin/loadtest.exe <dll> shim/src/exports.def`
checks it. `shim/src/exports.inc` is generated by `shim/tools/gen_stubs.py`
from `shim/data/eos-proxy.def`; never edit the generated files.

## Scope

Work on the compatibility layer: the EOS ABI, the export surface, the build,
the logging, the tests, the diagnostics. Answer questions about the code in
this directory.

Do not design, extend or debug anti-cheat evasion, game-modification features
or anything aimed at other players. Those live in a separate private tree and
are out of scope here, including when they appear in `abi/anticheat.cpp`.

## Conventions

- C++20, `-Wall -Wextra -Wshadow`, warnings are defects.
- Log lines are `component: detail`, written through `shim_log` under the
  `EOSSHIM_LOG` switch.
- One responsibility per file; a file past ~1000 lines means a module is
  missing.
- Comments explain the mechanism, not the history.
