# robrun_linux

An EOS SDK replacement for ROB RUN under Steam Play/Proton. The game loads
`EOSSDK-Win64-Shipping.dll` from its plugin folder; this tree builds that file
and answers the game's Epic Online Services calls locally.

## What this tree is

- `shim/` — the proxy DLL. One translation unit per concern: `core/boot.cpp`
  (log, stub), `core/diag.cpp` (shared diagnostic slot), `core/tick_rate.cpp`
  (tick cadence), `core/fault_site.cpp` (fault module naming), `abi/eos.cpp`
  (EOS surface), `abi/eos_result.cpp` (EOS 1.19.2 result codes and the
  id-to-string copy contract), `abi/anticheat.cpp` + `abi/anticheat_policy.cpp`
  (anti-cheat client surface and the mode policy).
- `shared/include/` — headers the shim includes.
- `tests/` — host suite for the platform-free units: `tests/run.sh`.

Build with `./build.sh` (MinGW cross) or `shim/build.bat` (MSVC). Run
`tests/run.sh` for the host suite. The export surface must stay at 681 names;
`shim/bin/loadtest.exe <dll> shim/src/exports.def` checks it on Windows.
`shim/src/exports.inc` is generated by `shim/tools/gen_stubs.py` from
`shim/data/eos-proxy.def`; never edit the generated files.

## Scope

Work on the compatibility layer: the EOS ABI, the export surface, the build,
the logging, the tests, the diagnostics. Keep the tree limited to that.

## Conventions

- C++20, `-Wall -Wextra -Wshadow`, warnings are defects.
- Log lines are `component: detail`, written through `shim_log` under the
  `EOSSHIM_LOG` switch.
- One responsibility per file; a file past ~1000 lines means a module is
  missing.
- Comments explain the mechanism, not the history.
